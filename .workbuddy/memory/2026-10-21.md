## RelaxCat：界面按钮/布局优化 + 主题启动 bug 修复

- 根因：Avalonia Fluent 默认 Button 底色在本项目里两套主题都渲染成深灰，浅色主题出现“深灰块 + 白字”的次要按钮，主次关系倒置；禁用状态的 quiet/danger 文案按钮会变成实心灰 chip。
- `App.axaml`：两套 ThemeDictionaries 新增 Control/ControlHover/ControlPressed/ControlBorder/Danger/DangerSoft/AccentInk/AccentHover/AccentPressed/Overlay 画笔；按钮 base + `:pointerover/:pressed/:disabled /template/ ContentPresenter#PART_ContentPresenter` 全状态覆盖（已用“临时洋红 hover”验证覆盖确实生效）；primary 禁用改用 AccentSoft；新增 `TextBlock.field` 小号 muted 标签样式。
- `MainWindow.axaml`：顶栏按钮间距/分隔线对齐、切换明暗改小号 quiet + ToolTip；首页工具条重排（左：缩放/紧凑 + 第二行排序；右：详细设置 + 全部移除），全部移除改 `danger`；卡片底部复制/移除改 muted + 收紧 padding；空状态收紧间距与文案宽度；`EmptyHint`/新增 `ThemeHint` 两个文案键。
- `SettingsView.axaml`：字段标签改 `Classes="field"`、分节标题统一、TabItem 加右侧 8px margin（避免选中块被内容区裁切），删除外观页与页脚重复的“更改会自动保存”。**踩坑**：给 TabControl 套 `Border.card` 会导致选中 Tab 背景被内容区裁切、内容溢出卡片，已回退。
- 真实 bug 修复（D-UI-004）：`ThemeIndex` 恢复值与字段默认值相同时 `Set` 不触发变更，主题不会被应用（settings 文件缺失时界面可能停在上一实例的变体）。抽出 `ApplyTheme` 并在 ctor 末尾显式调用。
- 测试：冒烟测试修正 `desktop-empty-dark.png` 一直拍到浅色的问题（现在断言启动即为深色）；新增 `desktop-hover-light.png`（headless `MouseMove` + `IsPointerOver` 断言）与 `settings-capture-dark.png`；曾尝试用 headless `window.DragDrop` 走真实拖放管线，但 `IStorageItem` 在 Avalonia 12 禁止用户实现、`BclStorageFile` 为 internal，已回退为直接调用 `DropPathsAsync` + `DropActive` 断言。
- 验证：build 0 警告；Core 58 通过；冒烟全 PASS。
- 备注：`TextBox` 的 placeholder 部件在 Fluent 12 里不叫 `PART_Watermark`（DLL 内只有 `PlaceholderText`），尝试过的水印样式选择器无效，已删除避免死代码。
