# RelaxCat v0.4.0（历史版本记录）

> 本文记录 v0.4.0 当时的功能和验证，不是当前安装建议或附件可用性声明。后续命名样式所属关系修正见 [验证记录](../excel-style-graph-validation.md#recorded-synthetic-run)；当前使用方式以 [README](../../README.md) 和对应发布提交为准。

本版扩展 Excel 样式优化，并提供四种界面语言。

## 本版变化

- 新增样式分区诊断：分别显示未压缩样式大小、ZIP 压缩大小、重复项与已知引用统计。
- 合并完全重复的基础 XF，并同步更新单元格格式与命名样式的引用。
- 在依赖审计覆盖时，对字体、填充、边框和自定义数字格式去重，再继续合并 XF。
- 新增可选「清理未引用样式（GC）」，支持单文件、批量处理及 CLI `--gc`；保留默认项、命名样式和有效引用。
- 组件去重/GC 遇到透视表、VBA、自定义部件或未知扩展等尚未覆盖的依赖时会跳过，并报告原因；原有完全重复 XF 去重仍可执行。
- 翻译迁移到外部 JSON，支持简体中文、日本語、English、한국어，每种语言均包含 281 个翻译键。新增语言只需添加符合格式的 JSON 文件并重启。
- 语言偏好改用稳定语言代码保存，兼容旧版设置；调整语言列表顺序不再影响已保存的选择。
- 改进多工作表标签栏和样式网格布局，为滚动条预留独立空间，避免遮挡内容。

## 历史包命名

- `RelaxCat-v0.4.0-win-x64.zip`：完整便携版，包含 .NET 10 运行时，无需另行安装。
- `RelaxCat-v0.4.0-win-x64-framework-dependent.zip`：轻量版，需要 .NET 10 x64 Runtime。

解压后进入对应文件夹运行 `RelaxCat.App.exe`。需要 Windows 10 或更新版本、x64；图片导出需要桌面版 Microsoft Excel。捆绑 Greenshot 需要 .NET Framework 4.8。

## 验证与边界

- 106 个 Core 用例通过直接反射运行器执行相同 xUnit 断言。标准 testhost 在本机因父进程访问权限限制无法运行。
- 桌面单文件/批量冒烟检查、四语言资源与占位符校验通过，覆盖语言切换、偏好迁移、40 个工作表/400 个样式的滚动布局。
- 本版新增优化的 Microsoft Excel 打开、保存、重开验收尚待完成；源工作簿和非目标包部件保持不变，结果始终写入新工作簿。
