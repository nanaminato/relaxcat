# RelaxCat v0.5.0-destructive.preview.2

**有损预发行版。保留原始工作簿，只处理有备份的副本。此版本不是稳定版，也不承诺格式或行为等价。**

样式兼容实现提交：`9eca37292c679b5a376a0ffd25ed46e16c190be7`。完整发布源码以对应标签为准。

## 本版变化

- 为显式开启的「破坏性样式清理」增加有限的 Office 元数据兼容，避免已识别的修订标识、空样式扩展声明和附属部件导致完全跳过。
- 仅允许已识别的类型和结构。未知扩展、未知引用、签名及其他未覆盖部件仍阻止索引改写，默认模式的限制不变。
- 识别共享字符串和工作表的注音字体引用。存在这些引用时保留完整字体表与原索引，避免破坏文本相关格式。
- 整理公开使用指南、故障排查、隐私提示和验收标准，区分历史记录、默认优化与有损功能。文档规范化不代表兼容性验收已完成。

## 使用

在 [Releases](https://github.com/nanaminato/relaxcat/releases) 查看此版本实际提供的附件及 SHA-256。Windows x64 便携包的命名为：

- `RelaxCat-v0.5.0-destructive.preview.2-win-x64.zip`：包含 .NET 10 运行时。
- `RelaxCat-v0.5.0-destructive.preview.2-win-x64-framework-dependent.zip`：需要 .NET 10 x64 Runtime。

解压后进入对应目录运行 `RelaxCat.App.exe`。需要 Windows 10 或更新版本、x64；图片导出另需桌面版 Microsoft Excel，离线样式优化不需要 Excel。捆绑 Greenshot 另需 .NET Framework 4.8。

先在单文件页面选择副本，明确勾选默认关闭的「破坏性样式清理」，分析后输出到独立的新文件。确认结果后再使用批量处理。源码 CLI 对应 `--destructive-styles`，用法见 [样式优化指南](../excel-style-optimizer.md#cli)。

在一个用户明确提供并授权分析的样式膨胀样本上：

- 命名样式与基础 XF 均从 48,847 减少到 1；单元格 XF 从 211 减少到 191。

- 工作簿从 564,358 减少到 43,334 字节，减少 **92.3215%**。
- 282 个字体因注音依赖完整保留；自定义数字格式也按现有限制保留。

旧版在此样本上被依赖检查阻止，样式未减少。新版本默认模式仍保留原样式，只可能因 ZIP 重新压缩改变文件大小。上述有损结果不是所有文件的收益保证，也不是格式等价证明。详情见 [兼容处理与验证范围](../destructive-compatibility-validation.md)。

## 有意损失与隐私

有损模式保留一个 Normal 身份，删除其他命名样式与基础 XF 身份，并断开原继承关系。当前外观、保护、打印、后续编辑、宏按名称或索引访问、外部模板和自动化可能改变或失效。VBA 二进制保留不代表宏行为正确。

`Verified=true` 仅表示该模式规定的结构与内容校验通过，不表示无损，也不是 Excel 无修复打开的保证。

本工具不会为兼容处理访问外部链接，但会保留原有链接、缓存和元数据。空白单元格不代表文件无敏感信息；此功能不是脱敏工具。不要公开完整分析报告或未经审核的样本。
