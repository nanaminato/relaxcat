# Excel 样式优化设计与验收标准

本文描述当前实现的设计约束和可复现验收方法。用户操作见 [样式优化指南](excel-style-optimizer.md)，有损模式另见 [实验说明](destructive-style-cleanup.md)。

## 目标与非目标

优化效果应以实际删除的样式定义和 `styles.xml` 未压缩字节减少量为主要指标，工作簿总大小和 ZIP 压缩大小分别报告。仅重新压缩 ZIP 不能作为样式优化有效的证据。

默认模式保留命名样式身份、已知引用和受支持的格式语义。显式有损模式允许删除名称和继承关系，但必须独立报告损失，不能复用默认模式的等价性表述。不以任意文件“缩小了多少”作为兼容性或生产成熟度保证。

## 分区诊断

统计 `numFmts`、`fonts`、`fills`、`borders`、`cellStyleXfs`、`cellXfs`、`cellStyles`、`dxfs` 等分区的条目数、序列化大小、重复数及已知引用数。

- 全部 `styles.xml` 使用实际未压缩字节数；分区使用独立 UTF-8 序列化大小，不能相加视为原始 XML 的精确分割。
- 引用统计未知时显示未知，不等同于零。语义重复不等同于可合并，未引用不等同于可删除。
- 预计输出、实际输出与原始值分别记录。ZIP 压缩大小估算不作为承诺。

## 引用与身份

已覆盖的核心引用链为：

```text
cellStyles.xfId -> cellStyleXfs <- cellXfs.xfId
                                     ^
                           worksheet c/row/col
```

基础 XF 和单元格 XF 还引用字体、填充、边框和数字格式。自定义 `numFmtId` 是标识符，不是数组序号；差分格式的内联定义不能直接按全局表处理。

Office 要求保留命名样式的名称及基础 XF 所属关系有效且唯一。因此，即使两个命名样式当前格式相同，默认模式也不能将它们合并到同一基础 XF。相关历史错误和回归覆盖见 [引用图验证](excel-style-graph-validation.md#recorded-synthetic-run)。

未知扩展、包部件或引用消费者会阻止索引变更。范围限制应可见，不把跳过说成优化成功或把未知消费者默认为不存在。

## 处理顺序

1. 读取并校验输入结构和已知索引。
2. 建立引用覆盖与保留根，判定当前模式能执行的操作。
3. 合并已覆盖的等价组件，更新相关引用。
4. 按身份约束处理基础 XF 与单元格 XF；GC 仅在明确开启时回收不可达定义。
5. 对显式名称清理应用候选约束；有损模式按独立计划处理 Normal、名称、基础 XF 和直接格式。
6. 最小范围重写样式 XML 与工作表样式索引，其余部件保留原字节。
7. 在临时输出上验证计划、引用、未修改部件和包，再提交到独立输出路径。

具体顺序和组合行为由模式实现与回归测试约束；以上是设计职责，不是允许跳过依赖检查的替代算法。

## 测试数据边界

自动化测试优先使用可重建的合成 OOXML。其他样本必须由用户明确提供并授权使用，不能仅凭“空白”或“已脱敏”推断权限。

公开报告只包含必要的结构统计和可复现方法，不包含样本内容、文件名、工作表名、路径、文档属性或未审核的名称/URI。样式、共享字符串、隐藏工作表、打印区域和属性中仍可能保留信息。

## 自动化覆盖

- 数万命名样式/基础 XF/单元格 XF、高索引映射和大量重复组件。
- 默认/保留槽、缺失与显式 apply 标志、命名所属关系、重复身份拒绝。
- 单元格/行/列引用、公式和缓存值、合并区域、不同 XML 编码及源字节不变。
- 未知依赖阻止、VBA 字节保留、签名相关部件与无效索引处理。
- 单文件与批量选项传递、失败继续、取消、同路径拒绝和已有输出规则。
- 再次运行不继续删除；区分部件内容不变与完整 ZIP 字节不变。
- 有损模式的单独删除计数、警告和校验范围，不能将结构通过解释为语义等价。

测试记录分别见 [引用图验证](excel-style-graph-validation.md) 和 [有损模式验证](destructive-style-cleanup.md#verification-performed)。历史测试数量属于对应提交，新增改动应重新执行相关检查，不能沿用旧结果。

## Microsoft Excel 验收

在目标 Windows 和 Excel 版本上完成以下流程，并记录实际版本、模式与工具提交：

```text
A = 原始工作簿
B = RelaxCat 写出的独立工作簿
C = B 经目标 Excel 打开、保存并重新打开后的工作簿
```

比较 A/B/C：

- 是否存在修复、格式上限或其他异常提示；
- `styles.xml` 未压缩字节、各分区数量和最终文件大小；
- 样式是否大规模重新生成；
- 公式、值、关键格式、合并、行列尺寸及打印效果；
- 保护、宏、命名样式编辑、外部模板和自动化依赖是否符合选定模式的预期。

默认模式以保留适用行为为验收目标；有损模式须人工确认损失可接受。二者都不能以第三方读取库打开成功替代 Excel 验收。未执行的项目明确标为未验证，不与自动化通过合并成“全部通过”。

## 实施记录（2026-11-03）

早期实现增加了分区诊断、基础 XF/组件去重和可选 GC，记录的 106 个 Core 用例通过了执行相同 xUnit 断言的临时反射运行器；当时标准 testhost 受父进程访问限制。此记录仅说明历史测试方式，不表示当前提交或 Excel round-trip 已通过。

后续实现增加了命名身份保护、完整索引改写阻止和独立有损模式。以当前指南和对应回归记录为准，不再用旧版“基础 XF 格式相同即可合并”的规则评估命名样式。
