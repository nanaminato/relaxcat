# 本轮改进范围与目的

依据：用户提供的项目评审对话，以及用户在当前对话中的明确需求与澄清。评审中的建议不是已确认的产品要求。

## 已落实

| 目的 | 修改 |
| --- | --- |
| 快速整理当前工作区 | 提供“全部移除”，释放预览与缩略图，不删除源文件、不改动已导出的 Excel 内容；忙碌时禁用 |
| 让不同批次的截图按时间自然排列 | 默认按文件最后修改时间从早到晚；支持从晚到早和导入顺序；新图片自动插入，时间相同时保留导入顺序 |
| 排序后仍导出正确的图片 | 图片具有稳定 ID，布局结果按 ID 找到源图片，不依赖完成计数映射 |
| 设置损坏后仍能启动 | 设置带 schemaVersion，支持现有无版本配置，保留上一份可读取的备份；主文件损坏尝试备份，两者失效时默认配置加错误提示 |
| 连续输入不反复写盘 | 400ms 合并自动保存；关闭时立即保存 |
| 文档不误导后续维护 | 修正 README 中设置只保留当前会话、Greenshot 配置由 RelaxCat 管理等过时说明 |

时间排序使用导入时记录的文件最后修改时间，不将其等同于相机拍摄时间、EXIF 或操作系统文件创建时间。选择导入顺序可恢复本次会话内的原始添加顺序。导出勾选与预览对象不因排序而改变。移除不会停止监控，后续新截图仍可进入工作区。

## 明确不加入本轮

用户明确要求保留现有工作流，不添加项目保存、仅导出未导出图片或自动导出。导出仍按当前工作区顺序处理已勾选图片，再次导出仍追加。

拖拽排序、剪贴板导入、文件拖入、工作簿选择、图片备注、OCR、PDF/OpenXML 后端、缩略图虚拟化和较大架构拆分，属于评审中的候选建议，未因此自动成为确认意图或本轮交付范围。
