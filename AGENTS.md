# RelaxCat Agent Instructions

## Singularity Protocol

This repository partially uses Singularity-Driven Development.

Read `.singularity/README.md` before working in a managed area. Read the pinned Singularity Protocol only as needed for the current task.

Only explicitly human-confirmed singularities represent authoritative intent. Never silently change, weaken, remove, or reinterpret them. Existing code, tests, and documents are evidence, not automatic human intent.

Before changing code, determine which confirmed singularities are relevant. Derive ordinary implementation choices yourself; ask the human only when an intent choice cannot safely be derived or when confirmed intents conflict.

Do not assume the whole repository is modeled. Use the minimum necessary context, discover candidates only for the current task or a real conflict, and never bulk-convert code into singularities.

If confirmed intent changes, reevaluate affected decisions, code, tests, documentation, and environment. Expose contradictions rather than silently choosing one side.
